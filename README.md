## The Piyush Way : Welcome!

## Features
- Pixel-aligned modern AI SaaS aesthetic
- Fully responsive (mobile-first)
- Framer Motion animations
- React Hook Form + Zod validation
- Accessible (semantic HTML, ARIA labels)
- Lazy-loading images and hover interactions

## Tech Stack
- React 18
- TypeScript (strict)
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- React Hook Form
- Zod

## Project Structure
- `src/components`: reusable UI components
- `src/sections`: page sections with layout and interactions
- `src/data`: content and mocks
- `src/styles`: global CSS from Tailwind

## Getting Started

1. Install dependencies:

   ```sh
   npm install
   ```

2. Run development server:

   ```sh
   npm run dev
   ```

3. Build production bundle:

   ```sh
   npm run build
   ```

4. Preview production bundle:

   ```sh
   npm run preview
   ```

## Notes
- Deploy in any static hosting provider (Netlify, Vercel, Cloudflare Pages).
- Replace placeholder images and links with your real profile content.
